# The SallaPush log catalogue: every log code of the native SDKs, with the level and the category it is always logged
# at, and the SDKs that log it. Codes are stable API: apps match on them in their log handlers.
#
# The Android SDK (SallaApp/mobile-push-android-sdk) and this SDK share this catalogue: each repository holds a copy
# with the same code lines.
# scripts/check-log-catalogue.sh checks this SDK on every pull request (scripts/verify.sh catalogue): the codes of
# Sources/SallaPushCore/Logging/Logger.swift, with their levels and categories, are exactly the lines below for "both"
# and "ios". To add a code, or to change a code's level, category or platform, change Logger.swift, the catalogue of
# Tests/SallaPushTests/LogCatalogTests.swift and this file in one pull request, then the same line in the shared
# catalogue and, for a code of both SDKs, in the Android SDK (CONTRIBUTING.md, "What needs care").
#
# Columns: code, level (error warn info debug verbose), platform (both ios android), category (lifecycle registration
# identity notifications events tags network storage consent extension). The category is the one the app's SDK logs
# the code with; the Notification Service Extension logs every code with the category extension.
